# scraplinux-releases

The release listing for ScrapLinux, served at
[scraplinux-releases.apiwow.net](https://scraplinux-releases.apiwow.net).

One entry per image, newest first: what changed, the size, the checksum and a
link to the ISO. The ISOs themselves are release assets on
[scraplinux](https://github.com/apiwo/scraplinux/releases) - nothing large
is stored here.
