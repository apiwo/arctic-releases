# arctic-releases

The release listing for Arctic Linux, served at
[arctic-releases.apiwow.net](https://arctic-releases.apiwow.net).

One entry per image, newest first: what changed, the size, the checksum and a
link to the ISO. The ISOs themselves are release assets on
[arctic-linux](https://github.com/apiwo/arctic-linux/releases) - nothing large
is stored here.
