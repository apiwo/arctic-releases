latest - 2026.09.01

Published 2026-09-02. First release under the ScrapLinux name - full rebrand from Arctic Linux (package manager alpm→scraps, .alpmz→.spz, GPL-3.0-or-later on ScrapLinux's own code, new gray/yellow branding). s66 (s6 + Obarun's 66 as PID1) is the new default init, replacing busybox - def (busybox) and openrc remain fully supported flavors. Full multilib/32-bit support and Steam. See the full release notes for the complete list, including one disclosed gap in the openrc tarball.

Live ISO

Boot-tested end to end in QEMU - a real, install-by-hand live environment (format/extract/chroot yourself, same as the manual tarball path below), not a guided installer. Includes a real build toolchain. Login: root or live, password scrap either way.

  • scraplinux-live.iso (500 MiB) - sha256

Tarballs (manual install)

  • s66 tarball (s6+66 init, the default) - sha256
  • def tarball (busybox init) - sha256
  • openrc tarball (missing libcrypt.so.2/libpam.so.0 - see release notes) - sha256
