latest - 2026.09.01

Published 2026-09-02. GPL-3.0-or-later on ScrapLinux's own code. s66 (s6 + Obarun's 66 as PID1) is the new default init, replacing busybox - busybox and openrc remain fully supported flavors. Full multilib/32-bit support and Steam. poweroff and reboot now actually complete on s66, udevadm works again so wifi drivers load at boot, and every tarball ships libcrypt.so.2 and libpam.so.0 - the gap previously disclosed against the openrc tarball is closed. See the full release notes.

Live ISO

Boot-tested end to end in QEMU - a real, install-by-hand live environment (format/extract/chroot yourself, same as the manual tarball path below), not a guided installer. Includes a real build toolchain. Login: root or live, password scraps either way.

  • scraplinux-live.iso (959 MiB) - sha256

Tarballs

Minimal tarballs

The same base system three times over, differing only in what runs as PID 1. Unpack onto a prepared root, then scraps add a kernel and a bootloader - there is no installer.

  • s66 tarball - s6 with Obarun's 66 on top, the default. Supervised services, dependency-ordered boot. sha256
  • busybox tarball - busybox init driven by /etc/inittab and /etc/rc.boot. The smallest and most predictable of the three. (Called the "def" tarball before this release.) sha256
  • openrc tarball - OpenRC, if you want runlevels and rc-service rather than a supervision tree. sha256

i3wl tarball (s66)

The s66 base with i3wl already installed - a dwl fork with i3-style binary-tree tiling, a StatusNotifierItem tray and a matching bar, started with i3wl or picked from a display manager's session list. Not published yet: the port builds, but its binary package is not in the mirror, so the tarball would be an s66 tarball under a different name. It lands once that package is built.
